# TASK-043の検出修正と制限

対象ロードマップ: **pqc-scan v0.3**（品質評価・検証基盤の包括的強化。[位置付け](../../docs/roadmap/v0.3/ROADMAP.md#v03-scope)）。

この変更は、042で確認した対応範囲内のFP4件・FN40件を直すためのものです。元の入力・正解・過去の測定は変更しません。実装・測定・レビューの完了条件は[修正計画](TASK-043-FIXES-PLAN.md)を参照してください。

ここでいう局所的な参照関係とは、同じファイル内で変数や引数がどの定義を指すかという関係です。外部moduleの読込やコードの実行で確かめるものではありません。

## 何を直すか

| 問題 | 修正 | 確認できる範囲 |
|---|---|---|
| Nodeの説明文字列、同名関数、名前の上書きがPQC扱いになる | 実callと明示したnode:crypto import・局所束縛を確認 | ファイル内の名目的な参照。実行やライブラリの実装は未証明 |
| 別名import・有限loop・RSA鍵の受け渡しを見逃す | alias、固定配列とタプルのfor...of、同期RSA生成から署名・検証への来歴を追跡 | 上限内の直接的な局所関係。任意式・外部module・非同期戻り値を推測しない |
| Python/Rustのimportと型付き操作を見逃す | 明示import、型、既知のML-KEM鍵pairの要素とreceiverを照合 | 存在する参照・用途。未使用importも実利用とは区別する |
| Java/RubyのSLH変種、旧称の大小文字を見逃す | 規格方式ごとのパラメータ境界と旧称の字句境界を確認 | 名称の一致。標準準拠の実装・安全性は未証明 |
| 破損構文の明示参照が消える | Java/Pythonの完全な引数・receiverとRustの未完了useを有界に回復 | 観測を残し、Partial診断も維持。不完全な値から方式を作らない |
| 無効SSHコメントやJava設定の書式を誤る | hashコメントを除外。代入/XML entry/static setPropertyの古典方式だけの列挙を確認 | 設定意図。実際の読込や交渉結果は未証明 |
| Gradle/gemspec/CIRCL/SBOMの依存を見逃す | 静的座標・block変数・packageとecosystemを照合 | 依存の宣言・存在。機能有効化や解決版は未証明 |

## 互換性と上限

CLI、公開型、出力Schema、規則ID/kind、Risk、Severity、Confidenceは維持します。新規依存は追加しません。組込判定を使うのは既定pattern・scope・kindが一致する規則だけです。カスタム指定は従来の汎用matcherを使います。修正した所見の数・位置・証拠・IDは変わります。同一の観測内容については既存のID生成を使います。

局所解析は、ASTの走査100,000ノード、深さ64、子要素4,096、同名束縛64、alias深さ8、scope参照128、有限配列32要素、候補4,096、証拠8,192 bytesなどの上限を持ちます。既存の1規則・1ファイル32所見の上限も維持します。上限に達したときはTruncatedとし、古い束縛や途中の配列から確定したように見せません。構文エラーはPartialとして残します。一般的な言語処理系の名前解決・実行可能性解析ではありません。

`API_NODE_CRYPTO_SIGN_RSA`は従来の`create(Sign|Verify)`のとおり署名と検証を対象にします。局所的なRSA鍵の利用が確認できる場合、factoryと利用箇所を別の静的参照として記録します。SHA256だけではRSAと判定しません。古いデータで検証側の注釈が欠けている場合、正しい検出を抑えず、旧成績を残して別版で注釈を修正します。

本変更は暗号実装を変更せず、鍵の生成・検体コード・依存DSLの実行も行いません。所見ゼロ、PQC参照、依存の存在のいずれも、耐量子安全性の証明にはなりません。

Gemspecは、既存のRuby文法を使って`Gem::Specification.new`のblock変数と範囲を確認します。block外、別blockで同名になった変数、再代入されたreceiverは推測しません。`spec.add_dependency`だけの裸の断片はGem仕様オブジェクトの来歴を示さないため、この検出では依存宣言にしません。Gradleと同様、依存の検査状態は従来のheuristicを維持し、完全なDSL解析とは扱いません。構文走査の上限による中断はTruncatedへ伝達します。
