## Changes

### Expanded scan coverage

- Add PHP, C#, C and C++, bringing source support to 11 languages.
- Expand source and dependency inspection and increase built-in rules from 125 to 139.
- Use recognized PQC references when reviewing migration from saved results.

See [supported inputs](../user/COVERAGE.md) for coverage and limits.
Source code is not executed. An algorithm reference does not establish actual
use or completed PQC migration.

### Findings and inspection scope

- Show surrounding source code while masking recognized credentials and private or shared key values.
- Fix cases where some inputs unnecessarily produced incomplete inspection.
- Explain incomplete inspection through diagnostics showing causes, affected files and next checks.

Masking does not find and hide every secret. Review reports before sharing them.
Saved reports keep their contents. Rescan to obtain the current display.
See [understanding reports](../user/REPORTS.md) for details.

## Compatibility and upgrade notes

The product version is `0.5.0`. Inventory v1, migration context/assessment v1,
SARIF 2.1.0, CycloneDX formats and existing output filenames keep their versions.
Choose the `static` or `network` variant for macOS Apple Silicon.
TLS and SSH diagnostics require the `network` variant and an explicit endpoint.

Added detections and corrected locations or evidence can change counts, IDs and
fail-threshold outcomes. Use the binary and rules from the same bundle.
Compare results with matching versions, scope and settings. Retain the previous
bundle for rollback and follow the [installation and update guide](../user/DISTRIBUTION.md).

## Validation scope

Scanning and output checks covered 35 selected OSS projects. Scan completion and
complete inspection of every input are distinct. Input restrictions and
unsupported or unresolved inspection remain visible as Partial or other states.
This evaluation does not guarantee accuracy or safety for all projects.
Zero findings do not establish safety or completed PQC migration.

The selection comprises 27 main projects emphasizing cryptographic implementations
and API use, plus eight comparison and regression projects. The main selection
contains three projects in each of nine language groups. Results for the two
populations are aggregated separately.
