# v0.5.0

[English](v0.5.0.md) · [導入と配布](../user/DISTRIBUTION.ja.md)

## 変更点

### スキャン対象の拡充

- PHP・C#・C・C++を追加し、対応言語を11言語にしました。
- ソースコードと依存関係の検査対象を広げ、組み込みルールを125件から139件にしました。
- PQC方式の参照を、保存した結果からの移行確認に利用できます。

検査対象と制約は[対応入力](../user/COVERAGE.ja.md)を参照してください。\
ソースコードは実行しません。\
方式名が見つかっても、実際の利用やPQC移行の完了を確認したことにはなりません。

### 結果と検査範囲の確認

- 検出箇所の前後のコードを表示し、認識した認証情報や秘密鍵・共有鍵の値をマスクします。
- 一部の入力で不要に検査未完了となっていた問題を修正しました。
- 検査が未完了の場合、原因と影響を受けたファイル、次の確認方法を診断から確認できます。

すべての秘密情報を見つけて隠す機能ではありません。\
共有前に内容を確認してください。\
保存済みのレポートは変わらないため、現在の表示を得るには再スキャンしてください。\
詳しくは[結果の読み方](../user/REPORTS.ja.md)を参照してください。

## 互換性と更新時の注意

製品バージョンは`0.5.0`です。\
Inventory v1、移行用の入力設定・評価のv1、SARIF 2.1.0、CycloneDXの形式と、既存の出力ファイル名は維持します。\
macOS Apple Silicon向けの`static`版と`network`版を使い分けます。\
TLS・SSH診断は`network`版で接続先を明示して実行します。

検出対象の追加や位置・根拠の修正により、件数、ID、終了判定の結果が変わる場合があります。\
同じ配布物のバイナリとルールを一組で使ってください。\
結果を比較するときは、バージョン・対象範囲・設定を揃えてください。\
差し戻し用に以前の一式を残し、[導入・更新手順](../user/DISTRIBUTION.ja.md)に沿って更新してください。

## 検証範囲

選定した35件のOSSでスキャンと出力の検査を行いました。\
スキャンの終了と、すべての入力の検査完了は別です。\
入力上の制約や未対応・未解決の検査は、Partialなどの状態で残ります。\
この評価から、あらゆるプロジェクトでの精度や安全性を保証するものではありません。\
検出がないことも、安全やPQC移行の完了を意味しません。

内訳は、暗号実装・暗号API利用を重視して選んだ主評価27件と、比較・回帰確認用の8件です。\
主評価は9つの言語グループから各3件を選び、比較対象とは分けて集計しています。
