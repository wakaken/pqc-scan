# v0.2.0リリース候補

承認済みのOSSロードマップをv1.0からv0.2.0へ変更します。機能の対象範囲と回帰基準は維持し、静的スキャンを正式対象、TLS／SSH／SSH KEXを実験的機能とします。製品版と出力スキーマの版は別で、Inventory v1、SARIF2.1.0、CycloneDX1.7は変更しません。

今回の変更は、有限上限を伴うソース全体の検査、汎用的な構文対応、Python／Ruby／Nodeの暗号参照の修正、依存関係の出典と選択済みローカルPOM／gemspecの参照、厳密な文字コード処理、検査できないバイナリの事前除外、診断の件数・例の集約です。条件・生成値・暗号化された入力の不確実性は残します。検出は調査候補であり、稼働中の脆弱性の認定ではありません。

同じ14件のOSSスナップショットで10形式を生成し、入力・検査範囲・残件分類と独立レビューを記録しました。公開候補には対象コミットのCIとクリーン導入の確認が必要です。[検証記録](../quality/V02-RELEASE-VALIDATION.md)を参照してください。

公開アーカイブは静的スキャン版のmacOS arm64を対象とし、ルール・ライセンス文書・SHA-256・検証可能なGitHubのビルド来歴を含める方針です。probe同梱版は既存のライセンスレビューが完了するまで配布準備として扱います。最新の検証済み0.2.xをベストエフォートで保守し、SLAや旧版修正を保証しません。候補のマージはタグ作成やGitHub Release公開を意味しません。
