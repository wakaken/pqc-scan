# v0.2.0

pqc-scan 0.2.0は、ローカルのソースコード、設定、依存宣言、公開証明書からPQC移行の調査箇所を探します。今回のリリース対象は静的スキャンです。TLS・SSH提示方式・SSH KEXは実験的機能として維持し、公開バイナリには含めません。

## 導入方法

バイナリアーカイブの対象はmacOS Apple Silicon（`aarch64-apple-darwin`）です。対応するルール、依存パッケージの通知文、導入・probeの案内を同梱します。[v0.2.0のRelease](https://github.com/wakaken/pqc-scan/releases/tag/v0.2.0)から取得し、SHA-256とGitHubのビルド来歴を公開対象のソースコミットと照合してから導入してください。手順は[インストールガイド](../user/DISTRIBUTION.ja.md)を参照してください。

ソースから導入する場合は、指定したRustツールチェーンを使います。他の環境向けのバイナリ配布とcrates.io公開は今回の範囲に含めません。

## 主な変更

- 有限の検出件数・処理量制限の中で候補ソース全体を検査し、未完了の理由を診断情報に残します。
- 汎用的な構文対応とPython・Ruby・Nodeの暗号参照の検出を改善し、原文の位置情報を保持します。
- 依存宣言、ロックの記録、ソースの由来を分け、選択済みのローカルPOM・gemspecを上限付きで参照します。
- 公開証明書の属性と信頼検証を区別し、暗号化された入力や未対応形式を未完了として扱います。
- UTF-16・UTF-32を厳密に復号し、検査できない既知のバイナリを事前除外します。人向けの診断は件数とファイル例にまとめます。
- 日英のHTML・Markdown、詳しい棚卸し、診断情報、独立したCycloneDX 1.7出力、棚卸し比較を利用できます。

所見は調査候補であり、稼働中の脆弱性やPQC移行完了の認定ではありません。条件・生成値、動的実行、暗号化された内容には不確実性が残ります。出力形式の版は製品版と別で、Inventory v1、SARIF 2.1.0、CycloneDX 1.7です。

先行する14件のOSS検査は、対象ソース、10出力のレポート、残った入力の分類、独立レビューとともに記録しています。これを0.2.0で新たに再実行した結果とは扱いません。公開候補は対象コミットのCI・配布・クリーン導入で確認します。[検証記録](https://github.com/wakaken/pqc-scan/blob/0aabacf568d388c36d197c895e0542b2de015abe/docs/quality/V02-RELEASE-VALIDATION.md)と、GitHub Releaseに記載する公開コミットのCI・ビルドのリンクを参照してください。

probe同梱版には、依存パッケージの公開前確認を残しています。保守は最新の検証済み0.2.xに対するベストエフォートとし、SLAや旧版への修正提供は保証しません。[脆弱性の連絡方法](../../SECURITY.md)も確認してください。
