# v0.2.0 release candidate

This candidate retargets the approved OSS roadmap from 1.0 to 0.2.0 without changing
its functional scope or regression criteria. Static scanning is the formal target;
TLS/SSH/SSH KEX remain experimental. Product version and report schema versions
are independent: inventory v1, SARIF 2.1.0 and CycloneDX 1.7 remain unchanged.

Changes include bounded full-source inspection, generic syntax compatibility,
Python/Ruby/Node cryptography-reference corrections, dependency provenance and
selected local Maven/gemspec context, strict wide-text decoding, non-scannable
binary pre-exclusion and concise diagnostic summaries. Conditional/generated and
encrypted inputs retain explicit uncertainty. Findings are investigation
candidates, not confirmed runtime vulnerabilities.

The same 14 OSS snapshots were scanned across 10 formats; source, scope, residual
classification and independent reviews are retained in validation evidence.
Current candidate acceptance requires exact-commit CI and clean installation.
See [validation](../quality/V02-RELEASE-VALIDATION.md).

The planned public archive is static macOS arm64, with rules, notices, SHA-256 and
verified GitHub build provenance. Experimental combined/all-probes archives remain
preparation only until their existing license reviews are cleared. Maintenance is
best-effort for the latest verified 0.2.x; no SLA/backport promise is added.
No tag or GitHub Release publication is implied by merging this candidate.
