# v0.2.0

pqc-scan 0.2.0 inspects local source code, configuration, dependency declarations
and public certificates for PQC migration investigation. Static scanning is the
release scope. TLS, SSH offers and SSH KEX remain experimental and are not included
in the public binary.

## Installation

The binary archive targets macOS Apple Silicon (`aarch64-apple-darwin`) and includes
the matching rules, dependency notices and installation/probe guides. Download it
from the [v0.2.0 Release](https://github.com/wakaken/pqc-scan/releases/tag/v0.2.0).
Verify its SHA-256 and GitHub build provenance against the release source commit
before installation. See the [installation guide](../user/DISTRIBUTION.md).
Source installation uses the pinned Rust toolchain. Other binary platforms and
crates.io publication are outside this release.

## Changes

- Inspect full source candidates within finite hit/work budgets, retaining explicit diagnostics when inspection cannot complete.
- Improve generic syntax handling and Python/Ruby/Node cryptography references; preserve original evidence positions.
- Keep dependency declarations, resolved records and source origins separate, with bounded selected-local Maven/gemspec context.
- Parse public certificate attributes separately from trust validation; keep encrypted and unsupported inputs incomplete.
- Decode supported UTF-16/UTF-32 text strictly, exclude known non-scannable binaries before inspection, and summarize human diagnostics by count and examples.
- Provide English/Japanese HTML and Markdown, inventory capture, diagnostics, separate CycloneDX 1.7 exports and inventory comparison.

Findings are investigation candidates, not confirmed runtime vulnerabilities or a
certificate of completed PQC migration. Conditional/generated values, dynamic
execution and encrypted contents retain uncertainty. Report schema versions are
independent of the product version: inventory v1, SARIF 2.1.0 and CycloneDX 1.7.

The earlier 14-OSS study retains its exact source snapshots, ten-output reports,
remaining-input classification and independent reviews; it is not relabelled as a
fresh 0.2.0 scan. Exact-commit CI, package and clean-install checks cover the release
candidate. See [validation](https://github.com/wakaken/pqc-scan/blob/0aabacf568d388c36d197c895e0542b2de015abe/docs/quality/V02-RELEASE-VALIDATION.md)
and the exact release build/CI links in the GitHub Release.

Probe bundles retain their dependency publication reviews. Maintenance is
best-effort for the latest verified 0.2.x, with no SLA or older-version backport
promise. See [security reporting](../../SECURITY.md).
