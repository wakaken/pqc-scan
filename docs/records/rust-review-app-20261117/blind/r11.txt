- **問題：** インデントは `line.text` の先頭にしか付与されません。値に改行が含まれると、後続行がコードブロックの外へ出られます。

例えば `line.line = 10`、`highlighted = false`、`line.text = "safe\n\n# injected"` では、次の Markdown が生成されます。

```markdown
      10 safe

# injected
```

`# injected` はインデントされておらず、見出しとして解釈されます。同じ入力の改行を CRLF または CR に置き換えても、それらを行末として扱う Markdown では同様に逸脱します。これはブラウザー実行とは独立した、コードブロック保持要件の違反です。

**修正案：** LF・CRLF・CR を考慮して `line.text` を物理行に分割し、各行にコードブロック用のインデントを付与してください。
