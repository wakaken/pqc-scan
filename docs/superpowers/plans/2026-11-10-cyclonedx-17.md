# Task 034: CycloneDX 1.7 export implementation plan

**Goal:** Add separately selected CycloneDX 1.7 documents without changing legacy outputs.

**Spec:** `docs/records/v0.2-roadmap/CONTINUATION-DECISIONS.md` (034 contract approved in the continuation conversation).

**Architecture:** A report-only conversion of validated native inventory v1, with allowlisted facts and explicit conversion loss properties. No cryptographic operations, dependency resolution or network calls at runtime.

**Ownership:** Executor owns `cyclonedx.rs`, its dedicated integration tests, pinned schemas, this plan and task evidence. Controller integrates `lib.rs`, CLI and bilingual user documentation.

## Constraints

- Rust 1.93.1; existing dependencies only.
- Additional filenames: `cbom.cdx-1.7.json`, `dependency-sbom.cdx-1.7.json`.
- Keep legacy six outputs and inventory v1 unchanged.
- A lexical algorithm reference is not an instantiated key or runtime protocol.
- Unknown algorithm/type/strength/trust stays unknown or omitted.
- Only `lock_resolved` versions populate component `version`; declared/reported values remain properties.
- No private bytes, raw source, arbitrary metadata, invented vulnerabilities or runtime-use claims.

## Implementation

- [x] Pin official 1.7 schemas, transitive schema references, license, exact upstream commit and SHA-256 digests; offline tests resolve only vendored documents.
- [x] Write failing tests for schema-valid empty and multi-kind exports, unique/resolving refs, observed-vs-declared provenance, loss ledger, unknown kinds and private canary omission.
- [x] Implement `write_cyclonedx_17(&ScanDocument, &Path) -> Result<Vec<PathBuf>>` and `documents(&NativeScan) -> Result<(Value, Value)>`.
- [x] Represent algorithm, certificate and public-key assets distinctly. Preserve algorithm OIDs and existing safe public fingerprints, key size and relationship refs when representable. Use `related-crypto-material`/`public-key` for public keys; never infer private-key objects from marker observations. Retain unknown/usage observations as safe properties/loss entries.
- [x] Run `cargo test -p pqc_scan_report --test cyclonedx_17`, inspect failures, then implement and repeat to green. Parent runs full workspace checks and CLI acceptance after integration.
- [x] Record exact source/artifact SHA, commands and actual outcomes, limitations and pending integration/review in `tasks/034/TASK-034-CYCLONEDX.md`; transition to review with controller integration and full acceptance explicitly pending.

## Review focus

- Cross-type references cannot dangle or be silently rewritten as software dependencies.
- Input SBOM claims never become proof of installed dependencies.
- Exported cryptographic metadata must not claim signature/trust verification.
- Malformed/future native vocabulary must not fabricate defaults.
- Offline schema validation must fail missing schema references instead of downloading them.
